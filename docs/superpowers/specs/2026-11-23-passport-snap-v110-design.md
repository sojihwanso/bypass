# 여권스냅 v1.1.0 설계: 오늘 한 페이지 · 쓸 수 있는 문장 · 기기 저장 · 현지용 치트시트

대상: `apps/passport-snap/index.html` (단일 정적 HTML, 바닐라 JS, 빌드 없음). 배포: main 푸시 → Vercel `/apps/passport-snap/`.
근거: `/impeccable critique` 2026-11-23 (24/40, P1 3개·P2 2개). 제품 맥락은 같은 폴더 `PRODUCT.md`, 시각 규칙은 `DESIGN.md`.

## 의도와 이유

여권스냅은 여행 1~2주 전 매일 20분 루틴(출발 전)과 현지 치트시트(여행 중)를 한 도구로 묶는다. 평가에서 두 장면 모두 약했다.
- 매일 돌아오는 학습자에게 홈이 "오늘 할 일 하나"를 보여주지 못하고(초록 CTA 8개, 동등한 DAY 카드 7장, 상태 없음), 새로고침하면 기록이 사라지며, 결과 화면은 실제 성과와 무관한 칭찬(+100 XP, "오늘 학습을 마쳤습니다")을 준다.
- 현지 여행자는 210문장 중 원하는 문장을 몇 초 안에 찾기 어렵고(모바일 첫 화면 1.5문장, 즐겨찾기 없음), 크게 보기에서 일본어가 어절 중간에서 끊긴다.

성공: 돌아온 사용자가 홈 첫 화면에서 오늘 할 DAY와 진행 상황을 바로 보고 한 번에 시작한다. 새로고침해도 진도가 남는다. 결과 화면이 사실을 말한다. 현지에서 고정(★)한 문장이나 장면 칩으로 3초 안에 문장을 띄운다.

## 목표

1. 홈 = 오늘 한 페이지 (채운 초록 버튼 1개)
2. 보상 = "쓸 수 있는 문장 n개" (XP 폐지)
3. 기록을 이 기기(localStorage)에 저장, 언어별 분리
4. 치트시트 현지 모드: ★ 고정, 장면 칩, 촘촘히 보기, 상단 고정 검색
5. 크게 보기 어절 단위 줄바꿈, 큰 글자 크기 토큰 정리
6. "제원" → "현지 정보"로 용어 변경 (사용자 결정)
7. 접근성: 학습 화면 대화상자화·포커스, h1, 키보드(방향키·숫자키)
8. 버전 1.1.0, 패치노트 추가 (bypass 앱 규칙)

## 하지 않는 것 (non-goals)

- 여행 날짜 입력, 날짜 기반 모드 전환 (다음 버전 후보)
- 서버 저장·로그인 (PRODUCT.md: 이후 Supabase 연동)
- 시각 세계(여행 수첩) 교체, 새 색·글꼴 도입
- 파일 분리·프레임워크 도입 (단일 파일 유지 여부는 계속 미정)
- 언어팩 콘텐츠(210문장) 수정

## 실패로 보는 것 (anti-goals)

- 홈이 여전히 여러 개의 동등한 초록 버튼을 보이는 것
- 틀렸는데도 칭찬하는 결과 화면
- 저장 실패(사생활 모드 등)로 앱이 깨지는 것 — 저장은 언제나 try/catch, 실패해도 메모리로 계속 동작
- 일본어 학습 기록이 중국어 화면에 나타나는 것

## 제약

- DESIGN.md 규칙 준수: Four-Step Tab, One Green Button, Source-First, Press-Only Depth, Pencil Gray, 터치 44px, 동작 줄이기, 확대 허용.
- 기존 기능·문구 유지(명시한 변경 제외). 언어팩 구조 유지(새 기능은 언어 무관하게 동작).
- 외부 라이브러리 없음. `Intl.Segmenter`는 지원 브라우저에서만 쓰고 없으면 기존 동작.

## 접근 방식 (Approaches)

1. **단일 파일 안에서 기능별로 고치기 (선택)** — 기존 렌더 함수(`renderCourseGrid`, `renderQuizScreen` done 분기, `renderPhraseList`, `openShowCard`)와 `state`를 확장하고, 저장 계층 하나(`store`)만 새로 둔다. 배포·구조가 그대로라 위험이 가장 작다.
2. 파일을 JS/CSS/언어팩으로 분리한 뒤 고치기 — 유지보수에는 좋지만 단일 파일 유지 여부가 미정이고, 이번 목표와 무관한 변경이 커진다. 제외.
3. 홈만 새 화면으로 다시 만들기 — 기존 DAY 그리드·위젯을 버리고 처음부터. 리디자인 범위로 커지고 DESIGN.md 세계를 흔든다. 제외.

## 상세 설계

### A. 저장 계층 (`store`)

- 키: `passportsnap.v1` (JSON). 음성 설정 키 `passportsnap.voiceGender`는 그대로.
- 형태:
  ```
  { version: 1, lang: 'ja', courseMode: 7, showKoPron: true, phraseDensity: null|'compact'|'detail',
    langs: { ja: { completed: { '7-1': '2026-11-23', ... },   // 레슨 키 → 완료한 로컬 날짜(YYYY-MM-DD)
                   usable: [phraseId, ...],                    // 쓸 수 있는 문장
                   favorites: [phraseId, ...],
                   notebook: { phrases: {...}, chars: {...} } }, zh: {...} } }
  ```
- 읽기: 시작 시 1회, 실패하거나 형태가 다르면 빈 기본값. 쓰기: 상태가 바뀌는 지점(레슨 완료, 정답/오답 기록, 즐겨찾기, 오답 삭제/비우기, 언어·코스·표시 설정)에서 `saveStore()`. 모두 try/catch.
- 언어별 분리: `state.completedLessons`(Set)와 `completedLabels`는 현재 언어의 `completed`에서 파생. 언어 전환 시 다시 계산.
- `state.xp`, `wrongReviewCount`는 삭제. 통계 카드 "오답 복습 n회" → "오답노트 n문장"(현재 노트 개수).
- "저장 안 함" 배지 → "이 기기에 저장". 저장 불가 환경이면 "저장 안 됨" 유지(감지: 시작 시 쓰기 테스트).
- 오답 삭제 후 토스트에 [되돌리기] 버튼(4초). 토스트는 지금 텍스트 전용이므로 선택적 action 인자를 추가.

### B. 홈: 오늘 한 페이지

- 오늘 DAY = 현재 코스에서 완료하지 않은 첫 레슨. 모두 완료면 "코스 완료" 상태.
- 오늘 이미 완료: 현재 언어·코스에서 완료 날짜 == 오늘인 레슨이 있으면 hero가 "오늘 분량 완료" 상태. 이 상태의 주 버튼은 없고(채운 초록 없음) "내일 DAY n 미리 보기"(outline)와 "랜덤 10문장 퀴즈"(soft) 제공.
- hero 구성(오늘 할 일 상태): 배지 "DAY n / 총 N" · 제목(레슨 이름) · 한 줄 설명(문장 수 · 약 20분) · 코스 진행 막대(완료 n/N) · 주 버튼 "DAY n 시작 →"(유일한 채운 초록) · 코스 토글(7일/14일)은 hero 안 보조로 유지.
- 20분 타이머: 오른쪽 위젯 칸에서 hero 안으로 이동(작은 인라인: 남은 시간 · 시작/일시정지 · 초기화 · 20분/스톱워치). 오늘 DAY 시작 시 타이머가 멈춰 있으면 자동 시작(카운트다운 모드일 때만). 위젯 칸에서는 타이머 카드 삭제.
- 나머지 DAY: hero 아래 "전체 코스" 목록. 한 줄 = DAY 태그 · 제목 · 상태(완료 ✓ sage / 오늘 / 남음) · 오른쪽 outline 작은 버튼("복습" 또는 "미리 하기"). 카드 그리드·DAY별 초록 버튼 삭제.
- 섹션 머리의 [오답노트 (n)] · [랜덤 10문장 퀴즈]는 유지(outline/soft).
- 모바일: hero → 전체 코스 목록 → 위젯(현지 정보 노트 · 오늘의 한마디 · 통계) 순.

### C. 결과 화면과 보상

- 첫 시도 정답 = 기존 `quiz.completedCount`(재시도 정답은 세지 않음). 문항별로 첫 시도 결과를 기록해 쓸 수 있는 문장을 갱신:
  - 첫 시도 정답(구문 문항) → `usable`에 추가.
  - 오답(첫 시도든 재시도든) → `usable`에서 제거.
  - 문자 퀴즈는 구문이 아니므로 usable에 영향 없음.
- 결과 화면:
  - 제목: 레슨 → "DAY n 완료", 랜덤 → "랜덤 퀴즈 완료", 오답 복습 → "오답 복습 완료", 문자 → "<탭명> 퀴즈 완료". "오늘 학습을 마쳤습니다"는 레슨일 때만.
  - 숫자 3개: 첫 시도 정답 n/총 · 쓸 수 있는 문장 +k (총 m) · 틀린 문장 w (rose 계열 상자, w=0이면 sage "모두 한 번에 맞힘").
  - 주 버튼: w>0 → "틀린 w문장 바로 복습 →"(오답노트 복습 퀴즈 시작), w=0 → "코스로 돌아가기". 보조: "코스로 돌아가기"(w>0일 때 outline).
  - 현지 정보 보너스 팁은 유지하되 홈과 같은 1/8 반복을 피하려 무작위 유지(현행).
- 상단 세션 표시 "0 XP · 0강" → "쓸 수 있는 문장 m · n강". 통계 카드 "누적 XP" → "쓸 수 있는 문장".
- 퀴즈 진행 막대: 재시도 포함 진행으로 바꿔 끝에 100%에 닿게(완료 문항/(남은+완료)).

### D. 접근성·키보드

- `#quiz-screen`에 `role="dialog" aria-modal="true" aria-labelledby`(퀴즈 제목). 열릴 때 포커스를 화면 안 첫 주 버튼으로, 닫을 때 연 버튼으로 복귀. 열린 동안 `main`/topbar/tabbar에 `inert`.
- 미리보기: ←/→로 이전/다음 카드. 퀴즈: 1~4로 보기 선택, Enter로 정답 확인/다음.
- 문서에 h1 1개: 브랜드 영역의 앱 이름을 h1로(시각 변화 없음), 각 뷰 제목은 h2 유지.

### E. 치트시트 현지 모드

- 칩 줄 맨 앞에 "★ 고정 (n)" 칩, 이어서 전체 · 카테고리 7개. 칩 줄과 검색창은 화면 상단(topbar 아래)에 sticky.
- 문장마다 ☆/★ 토글 버튼(aria-pressed, "고정"/"고정 해제" 라벨). 크게 보기 상단에도 ★ 토글.
- 보기 밀도 토글 "촘촘히 / 자세히": 촘촘히 = 원문 · 한글 발음 · 뜻만, 팁 숨김, 동작은 [크게 보기]+[듣기] 아이콘 위주로 한 줄. 기본값: 화면 폭 640px 이하 촘촘히, 그 외 자세히. 사용자가 바꾸면 저장.
- 검색 결과 0건: "‘q’에 맞는 문장이 없습니다" + 장면 칩 3~4개 제안(카테고리) + 검색어 지우기 버튼.
- 칩에 표시하는 개수는 현재 검색어 기준으로 갱신.

### F. 크게 보기 줄바꿈과 글자 크기

- 원문을 `Intl.Segmenter(lang, {granularity:'word'})`로 나눠 단어 사이에만 `<wbr>`를 넣고 컨테이너는 `word-break: keep-all`. 미지원이면 현행 텍스트. 크게 보기(`#sc-jp`)와 학습 미리보기 카드에 적용.
- 기존 `fitShowText`(길이별 크기) 유지·점검.
- 큰 글자 토큰: `--fs-glyph: 28px`(타이머·가나·작은 한자), `--fs-glyph-lg: 38px`(문자 상세·한자 카드·미리보기 원문 상한), `--fs-glyph-xl: 56px`(문자 퀴즈). 인라인/템플릿의 25·30·32·24px는 가장 가까운 토큰으로. `#dceefa` → `--pastel-sky-hover` 토큰(DESIGN.md에 추가). DESIGN.md rounded 스케일에 실제 쓰는 6·8·9·11·13·14px 정리(토큰 추가 또는 근접 값 통일 — 빌더 재량).

### G. 용어 "현지 정보"

- 바꿀 곳: 상단 탭 "일본/중국 제원·꿀팁" → "일본/중국 현지 정보", 하단 탭 "제원·꿀팁" → "현지 정보", 노트 "현지 제원 노트" → "현지 정보 노트", 버튼 "제원 전체 보기" → "현지 정보 전체 보기", 제목 "일본 제원 및 현지 안내" → "일본 현지 정보", hero 설명·도움말 문구, aria-label "이전/다음 제원 노트". 언어팩 데이터 키(`specs`)와 함수명은 그대로.

## 검토에서 나온 세부 결정 (설계자 판단, 사용자 확인 대상)

1. **오답 복습 퀴즈:** 문항을 처음 낼 때는 `isRetry: false`로 넣어 첫 시도로 센다. 첫 시도에 맞히면 usable에 넣고 그 항목을 오답노트에서 뺀다("극복"). 틀리면 지금처럼 노트에 남고 재출제한다.
2. **"틀린 w문장 바로 복습":** 방금 끝난 퀴즈에서 틀린 항목만으로 새 복습 퀴즈를 만든다(세션별 틀린 목록 보관). 오답노트 화면의 [오답노트 복습 퀴즈]는 지금처럼 노트 전체에서 낸다.
3. **완료 날짜:** `completed`에는 처음 완료한 날짜만 기록하고 복습으로 덮어쓰지 않는다. "오늘 분량 완료" = 처음 완료 날짜가 오늘인 레슨이 하나라도 있음(미리 하기로 뒤 DAY를 끝낸 경우 포함). "내일 DAY n"의 n = 완료하지 않은 첫 레슨.
4. **"+k":** k = 이번 퀴즈로 새로 추가된 문장 수(이미 있던 문장을 다시 맞힌 것은 제외). 오답으로 빠진 문장이 있으면 같은 칸에 "r개 다시 연습 필요"를 따로 적는다. 순증감 숫자는 쓰지 않는다.
5. **코스 완료 상태:** 모든 레슨을 끝내면 hero는 "코스 완료" 상태가 우선한다(오늘 끝낸 경우 "오늘 마지막 DAY까지 끝냈어요"). 채운 초록 버튼 없음. outline [틀린 문장 복습](노트가 비어 있지 않을 때) · soft [랜덤 10문장 퀴즈] · 텍스트 링크형 [다른 코스(14일/7일)로 다시 보기].
