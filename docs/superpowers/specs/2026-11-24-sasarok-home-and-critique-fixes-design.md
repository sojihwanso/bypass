## 왜 하는가

1. 홈이 심심하다. 처음 들어온 누구나 '해운 정보 사이트'라는 걸 바로 알아봐야 한다(사용자 요청).
2. 디자인 심사에서 나온 문제를 작은 것까지 모두 고친다(사용자 선택: "작은 것들까지 전부", 첫 순서는 "선종 화면 표 위치 + 모바일 표").
3. 겉모습은 지금 틀을 유지하되 해운 느낌을 조금 더한다(사용자 선택).

## 목표 / 하지 않을 것 / 실패로 보는 것

- 목표: 홈 첫 화면에서 해운 사이트임이 바로 읽힌다. 선종에서 선사 표까지 가는 길이 짧아진다. 휴대폰에서 실습·병역 정보가 가려지지 않는다. 대비 기준(4.5:1)을 넘긴다.
- 하지 않을 것: 선사·선종 데이터 내용 수정, 제보 게시판 서버 연결, 해운 소식 서버 연결, 사이트 전체 색·글꼴 교체.
- 실패로 보는 것: 장식이 늘어 표가 다시 아래로 밀림, 다크모드에서 그림이나 글자가 깨짐, 없는 숫자나 후기를 지어 넣음, 안 되는 기능을 되는 것처럼 보이게 함.

## 결정된 것

### 홈 히어로 (C)
- 낮 그림: 안티그래비티 생성(1376×768). 밤 그림: 안티그래비티 한도로 Gemini 웹에서 생성(1024×572, 미리보기 크기).
- 라이트모드는 낮 그림, 다크모드는 밤 그림. 테마 전환 시 즉시 바뀜.
- 그림 왼쪽 빈 하늘 위에 제목 "배 종류부터 정하면 / 지원할 회사가 좁혀집니다", 한 줄 설명, 주황 '선종 고르기' 버튼(선종 목록으로 이동).
- 휴대폰: 그림을 위(높이 약 180px), 글을 아래에 쌓음.
- 밤 그림 오른쪽 아래에 Gemini 반짝이 워터마크가 있음 → 두 그림 모두 아래쪽을 같은 비율로 잘라 워터마크가 어떤 화면에서도 안 보이게 함.
- 웹에 쓰므로 webp로 변환해 `apps/ship_info/assets/`에 둠.

### 홈 배치 (심사 P2)
- 선종 목록을 홈 첫 카드(왼쪽 넓은 칸)로 올림. 오른쪽에 즐겨찾기(비었으면 한 줄), 해운 소식, BYPASS 소개(차분한 카드로 낮춤).

### 심사 반영 순서 (사용자가 고른 순서대로)
1. layout: 선종 화면에서 필터·표를 장단점 위로. 장단점은 처음 3줄씩만 보이고 '더 보기'. 홈 배치와 히어로.
2. adapt: 640px 이하 선사 표를 카드형으로(회사명, 구분, 규모·태그, 실습·예비역 배지). 체크박스·별·칩 누르는 영역 44px 가까이. 휴대폰 머리 영역 높이 줄이기.
3. colorize: 신뢰 태그를 색 대신 채움 정도로(보도 꽉 참, 환산 테두리, 추정 점선), 비교 화면도 같은 태그. '회사 제출' 등 근거 태그는 중립 회색. 선택된 칩·플레이스홀더 대비 4.5:1 이상.
4. bolder: 히어로가 해운 느낌을 맡으므로 여기서는 작게만: 숫자 자체로 신뢰 수준이 드러나게(보도 숫자는 진하게, 추정은 옅게).
5. harden: 비교 목록 localStorage 저장, 필터 조건을 주소에 담기, 선사 상세에서 걸러 둔 표로 돌아가기, 제보 '보내기'를 서버 연결 전 상태로 표시(비활성 + 안내).
6. clarify: '선대/선단 규모' 통일, '비교/비교에 담기' 통일, '없음'과 '미정' 배지 분리, 보도·환산·추정 설명을 표 위로.
7. polish: 버전 표시(우측 상단, 버전 왼쪽·bypass 로고 오른쪽 / 최하단 중앙), 버전 5번 누르면 이스터에그 창과 '패치노트' 버튼, 높이·스타일 맞춤, 소식 카드 잘림, 비교 표 세로선.

## 빌더 점검 후 정한 것 (Claude의 판단)
- **심사 기록의 나머지 항목도 모두 포함**(사용자: "작은 것들까지 전부"). 단계별로 나눠 넣는다.
  - layout: footer '읽기 전에'는 홈에서만 펼치고 상세 화면에서는 접기.
  - adapt: 행 클릭을 키보드로도(`tr.row`, `.trow`에 포커스·Enter), `.qtabs` 화살표 키 이동.
  - colorize: `.status` 왼쪽 강조 막대를 테두리 전체로 교체.
  - harden: 열 머리 눌러 정렬, '필터 결과 전부 비교에 담기', 선종을 옮겨도 선종과 무관한 필터(회사 구분, 실습생 선발, 예비역, 국적)는 유지, 빈 결과일 때 결과를 0으로 만든 필터 이름 알려 주기, 비교 담기·빼기를 화면낭독기에 알리기(aria-live).
  - clarify: 표 머리에 짧은 도움말(title과 '?' 표시).
  - polish: 소식 화면 날짜칸·초기화 버튼 높이, 필터 초기화 버튼 스타일 하나로.
- **주황 버튼 대비**: 강조색 토큰은 그대로 두고, 주황 바탕 위 글자를 흰색 대신 짙은 색(#16181d, 약 5.3:1)으로 바꾼다. 다크모드는 이미 짙은 글자라 같은 방식.
- **밤 그림**: 지금 받은 1024×572를 쓴다. 워터마크 부분을 잘라 낸 뒤 webp로 `apps/ship_info/assets/hero-night.webp`에 둔다(낮 그림도 같은 비율로 잘라 `hero-day.webp`). 시안 폴더는 임시라 구현 첫 단계에서 바로 옮긴다. 더 선명한 원본은 Gemini 채팅 '선사록 다크모드 야간 배너 생성'에서 사용자가 '원본 크기 다운로드'로 받을 수 있다.
- **홈의 제보 게시판 카드**: 남긴다. 오른쪽 칸 맨 아래에 작게, '준비 중·저장 안 됨' 표시 유지. 휴대폰 쌓는 순서: 히어로 → 선종 → 즐겨찾기(비었으면 한 줄) → 해운 소식 → 제보 → BYPASS.
- **이스터에그 창**: `apps/seacal`의 버전 이스터에그와 같은 구조(버전·앱 이름 카드 + '패치노트' 버튼, 패치노트는 최신이 위). 그림(.art)은 이번에는 넣지 않는다(안티그래비티 한도). bypass 로고는 사이트 공통 `/assets/favicon.svg`를 쓰고 teambypass.vercel.app으로 연결. 사이트 공통 미니게임 `/assets/egg.js`는 붙이지 않는다(다른 앱들도 대부분 쓰지 않고, 단일 파일 구조를 유지).
