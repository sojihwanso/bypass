# 승선근무예비역 도우미 (원본)

`apps/seaduty/`는 배포본이고, 이 폴더가 원본과 작업 도구입니다. 주소: `/apps/seaduty/`

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `site/index.html` | 앱 원본(스타일·스크립트 포함 한 파일). **수정은 여기서** |
| `build.sh` | 원본 → `apps/seaduty/index.html` (cbttest와 같은 파비콘을 넣음) |
| `build_holidays.py` | 1990~2100 공휴일 → `apps/seaduty/data/holidays.json` (온라인 모드에서 받아 씀) |
| `../../supabase/031_seaduty_sync.sql` | 복구 코드 서버 백업 표·함수. Supabase SQL Editor에서 한 번 실행 |

```bash
bash tools/seaduty/build.sh                       # 앱 수정 후
pip install ephem holidays korean-lunar-calendar  # 공휴일 다시 만들 때만
python3 tools/seaduty/build_holidays.py --check   # 생성 + 교차 검증
```

## 계산 규칙

- 인정일수 = 승선일~하선일(양 끝 포함) + 업무상 휴직 기간 + 군사교육소집 기간 + 휴가 사용일수(+ 직접 넣은 추가 인정일수). 편입일 전 날은 빼고 셉니다.
- 휴가: 외항선 30일당 7일(선원법 제70조① 6일 + 제62조⑤ 1일), 내항·연해 6일, 어선은 1년 20일 + 1년을 넘는 매월 1일, 모두 올림. 줄마다 직접 입력할 수도 있습니다.
- 휴가 사용: 하선 다음 날부터. 공휴일(일요일·대체공휴일·선거일·임시공휴일)과 근로자의 날·노동절은 휴가 사용일과 인정일에서 빼고, 토요일은 셉니다(선원법 제71조). 다음 승선이 먼저 오면 남은 휴가는 이월되고, 군사교육소집 중에는 휴가가 멈춥니다.
- 1,095일이 되는 날을 복무 완료일로 봅니다(법령에는 '3년'만 있고 일수 환산 규정은 없음).
- 기한: 편입일 + 5년 - 1일, 출생연도 + 30년의 12월 31일(병역법 제23조의4, 제2조②).
- 같은 기록으로 기존 엑셀 계산기(복무만료계산기 배포용)와 대조했을 때 승선 872일·휴가 206일·교육 19일로 합계가 같았습니다. 다만 엑셀 공휴일 표에는 2022. 9. 12.과 10. 10. 대체공휴일이 빠져 있어서 만료일이 엑셀보다 이틀 늦게(2022. 12. 31.) 나옵니다. 앱 쪽이 규정에 맞습니다.

## 공휴일 자료

- 「관공서의 공휴일에 관한 규정」[시행 2026.5.11] 연혁대로 만듭니다: 노동절(2026~), 제헌절(~2007, 2026~), 한글날(~1990, 2013~), 식목일(~2005), 신정 연휴, 대체공휴일 단계(2013·2021·2023·2026).
- 음력은 한국 표준시 기준으로 천문 계산합니다. 2050년까지 korean-lunar-calendar(한국천문연구원 자료)와, 2100년까지 python-holidays(KR)와 모두 일치합니다.
- 1990~2025년 공휴일 전체가 python-holidays(KR)와 같습니다. 2026년부터는 개정 규정(노동절·제헌절)만큼 다릅니다.
- 선거일은 공직선거법 제34조 규칙으로 계산한 예정일이고, 임시공휴일은 2026년 11월까지 확인된 것만 들어 있습니다. 새 임시공휴일이 지정되면 `PAST_SPECIAL`에 넣고 다시 만드세요.
- 크기: 2,247건, JSON 46,857바이트(gzip 3,506바이트). 일요일은 넣지 않고 앱이 요일로 계산합니다.

## 온라인·오프라인

- 기본은 온라인: `data/holidays.json`을 받아 계산하고 복구 코드 백업을 씁니다.
- 연결이 끊기거나 자료를 받지 못하면 자동으로 오프라인 모드로 바뀝니다. 이미 받은 자료가 있으면 계속 쓰고, 없으면 일요일과 양력 고정 공휴일만으로 계산합니다(설·추석·부처님 오신 날·선거일·임시공휴일 빠짐). 다시 연결되면 자동으로 돌아갑니다.
- 오프라인용 내장 자료와 서비스 워커(인터넷 없이 페이지 열기)는 아직 넣지 않았습니다.
