지원 파일과 AI 연결 안내

PDF, PPTX, DOCX, HWPX/HWP, 필기·칠판·시험지 사진, MP3/M4A/WAV, MP4, 붙여넣기 텍스트를 여러 개 묶어 하나의 노트로 만들 수 있습니다. 구형 .doc·.ppt나 일부 복잡한 .hwp는 PDF로 저장해 올려 주세요. 모든 파일 파싱은 이 브라우저 안에서만 이루어지며 서버로 업로드되지 않습니다.

Google AI Studio 무료 Gemini API 키(주력)와 OpenRouter 무료 모델(텍스트 폴백) 조합을 기본으로 안내합니다. 사진·음성 분석과 맞춤법 검사는 Gemini가 맡고, 일일 한도에 도달하면 OpenRouter의 한국어 검증 통과 무료 모델로 이어서 정리할 수 있습니다. 이미 OpenAI·Anthropic·Gemini 유료 키가 있다면 설정에서 바로 연결할 수 있습니다.

노트 화면의 「A4 PDF 인쇄」를 누르면 브라우저 인쇄 전용 스타일시트(@page)로 표나 도식이 페이지 중간에 잘리지 않게 깔끔한 벡터 PDF로 저장됩니다. 저장된 노트와 오답 카드는 이 기기(IndexedDB)에 사본이 남아 비행기 모드에서도 열람하고 복습할 수 있습니다.

개인정보 및 AI 무료 티어 안내 업로드한 원본 파일과 AI API 키는 Bypass 서버에 절대 저장되지 않습니다. 단, 무료 AI 티어(Google AI Studio 무료 · OpenRouter 무료 모델)를 사용할 때 입력 내용은 해당 AI 제공사의 정책에 따라 모델 개선에 활용될 수 있으므로 민감한 개인정보가 담긴 문서는 가린 뒤 사용해 주세요.

AI 비용은 사용자가 연결한 엔진으로 직접 처리되며, API 키는 이 브라우저에만 보관됩니다.

API 키 발급·찾기가 어렵다면? 평소 사용 중인 AI(Gemini·ChatGPT·Claude 등)에게 “Google AI Studio 무료 Gemini API 키 발급받는 법 알려줘”라고 물어보면 단계별로 쉽게 찾으실 수 있습니다.

③ OpenRouter (무료 폴백 · 유료 확장)

④ 기타 직접 API 키 · ⑤ Chrome 내장 AI

분담을 켜면 사진·스캔을 읽는 1단계만 Gemini가 맡아 Gemini 호출이 노트당 1번으로 줄고, 혼잡에 덜 걸립니다. OpenRouter가 응답하지 않으면 그 단계는 Gemini가 대신 쓰고, Gemini가 혼잡하면 글자 자료는 OpenRouter가 정리합니다. 두 키 중 하나만 있으면 이 설정과 관계없이 있는 엔진으로 만듭니다.
