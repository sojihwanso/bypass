# 선사록 해운 소식 자동 수집 설정 (한 번만)

선사록 › **해운 소식**이 새 소식을 하루 한 번 자동으로 받으려면 두 가지를 해 두어야 합니다.
API 키나 비밀 값은 **필요 없습니다**.

## 1. SQL 실행

Supabase SQL Editor 에서 `supabase/038_ship_news.sql` 전체를 붙여 넣고 **Run** 을 누릅니다.
- 소식을 담아 두는 표(`ship_news`)와 마지막 수집 시각을 적는 표(`ship_news_meta`)가 생깁니다.

## 2. 함수 올리기

1. Supabase 대시보드 → 왼쪽 **Edge Functions** → **Deploy a new function** → **Via Editor**
2. 함수 이름: `ship-news` (정확히 이 이름)
3. 편집기 내용을 지우고, 이 폴더의 `index.ts` 전체를 붙여 넣은 뒤 **Deploy**
4. 함수 화면의 **Details**(또는 Settings)에서 **Verify JWT / Enforce JWT verification** 을 끕니다. 공개 소식이라 로그인이 필요 없습니다.

## 3. 확인

브라우저 주소창에 아래 주소를 열어 `{"updated": "...", "items": [...]}` 모양의 글자가 나오면 됩니다.
처음 한 번은 소식을 모으느라 10초쯤 걸릴 수 있습니다.

```
https://itzdjdgjqcpmxdfssfel.supabase.co/functions/v1/ship-news
```

그다음 선사록 해운 소식 화면에 "하루 한 번 자동으로 새 소식을 받습니다"가 보이면 끝입니다.
함수를 올리기 전에는 사이트에 들어 있는 소식만 보이고 "자동 수집을 준비하고 있습니다"라고 나옵니다.

## 알아 둘 것

- **언제 모으나**: 마지막으로 모은 지 24시간이 지난 뒤 누군가 해운 소식을 열면 그때 모읍니다(예약 작업 없음).
- **어디서 모으나**: 해운 전문지 RSS 4곳(쉬핑뉴스넷, 해양한국, 한국해운신문, 카고뉴스)과 구글 뉴스 검색(해운·조선·항만·해외 해운사·선원 등 검색어 15개, 검색어마다 최신 10건).
  구글 뉴스 결과와 카고뉴스는 제목에 해운 관련 낱말이 있어야 받습니다. 같은 기사는 하나만 남깁니다.
- **담는 것**: 제목·매체·날짜·원문 링크·짧은 요약(120자)만. 45일 지난 소식은 지웁니다.
- **용량**: 표는 몇 MB 안팎입니다. 브라우저는 6시간에 한 번만 묻고, 지난번 이후 새 소식만 받아 갑니다.
  실제 사용량은 대시보드 **Usage** 에서 볼 수 있습니다.
- **안 될 때**: Edge Functions › `ship-news` › **Logs** 를 봅니다. 받지 못한 수집처는 `ship_news_meta.last_error` 에 적힙니다.
  수집처 하나가 막혀도 나머지는 계속 받습니다.
- 수집처나 검색어를 바꾸려면 `index.ts` 의 `SOURCES` 를 고친 뒤 다시 붙여 넣고 Deploy 합니다.
